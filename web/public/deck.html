How it works

The mechanism, in the reader's words

The slide that survives the meeting is the one that explains the machinery without naming a library.

  • The data is generated from a seed string, so it is the same on every machine and after every reload. It is not real, and the demo says so on its own gate.
  • Questions are answered by a model that can only read the demo's figures through two tools. It cannot produce a number; it can only ask for one.
  • When it cannot answer, it says which way it failed and offers questions that resolve. There is no second answer engine behind it.
  • Nothing a visitor does is stored. Making this a product would mean giving each visitor their own saved state, which is a different tier of the kit.
Built with demo-kit. The passcode gate is a boundary, not authentication — a real deployment sits behind the customer's own identity provider.
