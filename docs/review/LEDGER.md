# dl-finance-workbench — review rounds

Every round of the adversarial review loop, so the rounds can be compared. The protocol —
what the loop is, the binary verdicts, the independence rules and the stop condition — is
`vendor/demo-kit/packages/review/REVIEW.md`.

The loop stops when every reviewer returns yes, or when the severity rule says another round
would buy nothing: a Critical always buys one, a High buys one up to round four, a Low buys
none, three rounds is the floor and five the ceiling. `demo review --record` prints which
applied. This file is the loop's memory — the rule reads it to tell a loop that is converging
from one that is a treadmill, because the same gap appearing three rounds running is a
different problem from three rounds each finding something new.

Rounds are opened by `demo review` and filled in by `demo review --record`. Editing this
file by hand is fine and expected — add a line saying what changed between two rounds.
